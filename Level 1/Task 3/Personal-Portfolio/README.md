# 🌡️ Temperature Converter Website

A modern, interactive, and responsive **Temperature Converter Website** developed as part of the **Oasis Infobyte Internship (OIBSIP) – Task 3**.

The application allows users to convert temperature values between **Celsius, Fahrenheit, and Kelvin** with real-time validation and an easy-to-use interface.

---

## 📌 Project Overview

The Temperature Converter is a web-based utility designed to provide fast and accurate temperature conversions.

Users can:

- Enter a temperature value
- Select the input temperature unit
- Convert the value into other temperature units
- View all converted values simultaneously
- Get real-time validation messages
- Handle temperatures below absolute zero
- Clear and reset the converter
- View recent conversion history
- Use quick temperature values
- Copy conversion results
- Use the website on desktop, tablet, and mobile devices

The project focuses on creating a clean **UI/UX**, interactive components, and accurate JavaScript-based calculations.

## ✨ Features

### 🌡️ Temperature Conversion

Supports conversion between:

- Celsius (°C)
- Fahrenheit (°F)
- Kelvin (K)

The application displays all converted values simultaneously.

### 🔢 Numeric Input

Users can enter:

- Positive values
- Negative values
- Decimal values

Invalid input is detected and handled with user-friendly messages.
