# 🌟 Lumière | Modern Living

## OIBSIP Task 1 – Landing Page

A modern and responsive landing page designed for **Lumière | Modern Living**, a fictional lifestyle and e-commerce brand. The website focuses on clean UI/UX, elegant design, smooth navigation, and an engaging user experience.

---

## 📌 Project Overview

Lumière is a modern lifestyle website created as part of the **Oasis Infobyte Internship Program (OIBSIP)**.

The landing page presents a visually appealing interface for a lifestyle brand, including a hero section, product showcase, categories, brand information, customer reviews, FAQ, contact section, and interactive shopping features.

The project is designed using frontend technologies and is fully responsive across desktop, tablet, and mobile devices.

---

## 🎯 Objective

The main objective of this project is to design and develop a professional landing page that:

- Provides a clean and attractive user interface
- Creates a strong first impression through the hero section
- Provides easy and intuitive navigation
- Showcases products and categories effectively
- Provides a responsive experience on different screen sizes
- Demonstrates frontend development skills
- Implements interactive UI elements using JavaScript

---

## ✨ Features

### 🏠 Home Section
- Attractive hero section
- Brand introduction
- Call-to-action button
- Modern typography and visual design

### 🛍️ Shop Section
- Product cards
- Product images
- Product names and prices
- Add-to-cart functionality
- Wishlist interaction

### 🗂️ Categories
Products are organized into categories such as:

- Fashion
- Accessories
- Lifestyle

Users can select a category to view relevant products.

### 🔎 Search
- Search products by name or category
- Dynamic filtering of products

### 🛒 Shopping Cart
- Add products to cart
- Increase or decrease quantity
- Remove products
- Automatically calculate total price
- Cart count updates dynamically

### 💳 Demo Checkout
The website includes a simulated checkout experience for demonstration purposes.

Users can enter:

- Full Name
- Email
- Phone Number
- Address
- City
- PIN Code

Available demo payment methods:

- UPI
- Credit/Debit Card
- Cash on Delivery

> ⚠️ No real payment is processed. This is only a frontend/demo payment simulation.

### ✅ Payment Confirmation
After completing the demo checkout:

- Payment processing animation is displayed
- Payment success message is shown
- A unique demo Order ID is generated
- Order amount is displayed
- Selected payment method is displayed

### 📦 Order Tracking
A demo order tracking interface shows:

1. Order Confirmed
2. Order Being Prepared
3. Out for Delivery
4. Delivered

### 👤 Login
- Demo login interface
- User-friendly login modal

### ⭐ Reviews
Displays customer reviews and ratings to improve the overall appearance and credibility of the website.

### ❓ FAQ
Interactive Frequently Asked Questions section.

### 📩 Contact
Users can submit their name, email, and message through the contact form.

### 📱 Responsive Design
The website is designed to work on:

- Desktop
- Laptop
- Tablet
- Mobile devices

---

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Interactivity and dynamic functionality
- **Google Fonts** – Typography
- **Unsplash** – Demo product/visual images
- **LocalStorage** – Maintaining cart data in the browser
