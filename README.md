# OIBSIP Task 1 – Landing Page

## 📌 Project Overview

This project is a modern and responsive Landing Page developed as part of the Oasis Infobyte Internship Program (OIBSIP).

The main objective of this task is to design an attractive, user-friendly, and responsive landing page with a clean UI/UX, engaging visuals, and interactive elements.

## 🎯 Objectives

- Create a visually appealing landing page.
- Design a clean and professional user interface.
- Implement responsive design for different screen sizes.
- Organize webpage sections in a structured manner.
- Add interactive elements to improve user experience.
- Practice HTML, CSS, and JavaScript development.

## ✨ Features

- Responsive navigation bar
- Attractive hero section
- Call-to-action buttons
- Well-structured content sections
- Modern UI/UX design
- Interactive elements
- Responsive layout
- Smooth scrolling
- Visual effects and animations
- Footer section

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file.
4. Right-click on the file.
5. Select "Open with Live Server".
6. The website will open in your browser.
