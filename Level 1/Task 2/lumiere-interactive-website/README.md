# Lumière | Modern Living

## OIBSIP – Task 1: Landing Page

Lumière | Modern Living is a modern and responsive lifestyle landing page designed as part of the Oasis Infobyte Web Development Internship Program (OIBSIP).

The website is designed with a clean, elegant, and minimal user interface to provide visitors with a smooth and engaging browsing experience.

---

## Project Overview

Lumière is a modern lifestyle and e-commerce-inspired website that showcases fashion, accessories, and lifestyle products.

The website includes a visually appealing homepage, product sections, categories, customer reviews, FAQ, contact section, shopping cart, and a simulated checkout experience.

The main focus of the project is to create an attractive, responsive, and interactive frontend website using HTML, CSS, and JavaScript.

---

## Objectives

The main objectives of this project are:

- To create a professional and attractive landing page
- To design a clean and user-friendly UI/UX
- To implement responsive web design
- To create easy and intuitive navigation
- To showcase products in an organized manner
- To add interactive frontend features
- To demonstrate HTML, CSS, and JavaScript skills

---

## Features

### Home Section

- Modern hero section
- Brand introduction
- Attractive typography
- Call-to-action button
- Smooth navigation to different sections

### Shop Section

- Product showcase
- Product images
- Product names and prices
- Add to cart functionality
- Wishlist interaction
- Responsive product grid

### Categories

The website provides different product categories:

- Fashion
- Accessories
- Lifestyle

Users can select a category to view products belonging to that category.

### Search

The website includes a search feature that allows users to search for products by:

- Product name
- Category

The product list updates dynamically based on the search input.

### Shopping Cart

The shopping cart provides the following functionality:

- Add products
- Remove products
- Increase product quantity
- Decrease product quantity
- Automatically calculate the total price
- Display the number of items in the cart

Cart information is stored using browser Local Storage.

### Demo Checkout

The website contains a simulated checkout page to demonstrate a complete e-commerce user flow.

Users can enter:

- Full Name
- Email
- Phone Number
- Address
- City
- PIN Code

Payment options include:

- UPI
- Credit/Debit Card
- Cash on Delivery

### Demo Payment

The payment system is completely simulated for demonstration purposes.

After clicking the payment button:

1. A payment processing screen is displayed.
2. The system simulates payment processing.
3. A payment successful message is displayed.
4. A unique demo order ID is generated.
5. The order amount and payment method are displayed.

> Note: No real payment is processed and no money is charged.

### Order Tracking

The website also provides a demo order tracking interface with the following stages:

1. Order Confirmed
2. Order Being Prepared
3. Out for Delivery
4. Delivered

### Login

A simple demo login interface is included to provide a realistic e-commerce experience.

### Customer Reviews

The website contains a customer reviews section with ratings and feedback to make the page more engaging and realistic.

### FAQ

An interactive Frequently Asked Questions section is included to provide useful information to visitors.

### Contact Section

Users can submit their:

- Name
- Email
- Message

through the contact form.

### Newsletter

Visitors can subscribe to the demo newsletter by entering their email address.
